## 概述

### 目標
本模型透過分析 SEC 10-Q 報告中的**風險因素**文字來預測**債券報酬率**。目標是找出財務文件中使用的語言與債券價格變動之間的關聯性。

### 研究假說
> 季度報告中「風險因素」章節所使用的詞彙和表達方式，包含了公司債券未來表現的預測信號。

### 使用資料

| 來源 | 說明 | 數量 |
|------|------|------|
| CSV (csv_raw/) | TRACE 債券報酬資料 | 132,032 筆觀察值 |
| SEC 文件 | 風險因素文字 (10-Q) | 1,035 家公司 |
| 期間 | 2019-2024 | 6 年 |

## 資料處理流程

### 步驟一：載入 CSV 檔案

```python
csv_raw/
├── Earning_announcement_with_TRACE_2019_*.csv  (19,405 筆)
├── Earning_announcement_with_TRACE_2020_*.csv  (19,145 筆)
├── Earning_announcement_with_TRACE_2021_*.csv  (20,421 筆)
├── Earning_announcement_with_TRACE_2022_*.csv  (21,882 筆)
├── Earning_announcement_with_TRACE_2023_*.csv  (23,911 筆)
└── Earning_announcement_with_TRACE_2024_*.csv  (27,268 筆)
                                        總計: 132,032 筆
```

**使用的關鍵欄位:**
- `tic`: 股票代碼
- `rdq`: 季度報告日期
- `bond_return`: 第 0 天報酬
- `bond_return_plus_day_X`: 第 X 天報酬

### 步驟二：掃描 SEC 文件

```python
sec_10q/sec-edgar-filings/
├── AAPL/
│   └── 10-Q/
│       ├── 0001193125-19-023456/
│       │   └── full-submission_rf.txt  ← 第一行 = 日期 (YYYYMMDD)
│       └── ...
├── MSFT/
│   └── ...
└── ... (1,053 家公司)
```

**`full-submission_rf.txt` 檔案格式:**
```
20230315                          ← 申報日期 (第 1 行)
Risks, Uncertainties and Other    ← 風險因素文字 (第 2 行起)
Factors That May Affect Future
Results Our operating results...
```

### 步驟三：資料配對

針對每筆 CSV 觀察值：
1. 提取股票代碼和 `rdq` 日期
2. 尋找 `rdq` **之前**最近的 SEC 文件
3. 將風險因素文字與債券報酬進行關聯

```
CSV 觀察值:                   對應的 SEC 文件:
├── ticker: AAPL              ├── 日期: 2023-02-15
├── rdq: 2023-03-20   →       └── 文字: "Our business is subject
└── bond_return: 0.012            to risks including..."
```

**結果:** 成功配對 95,315 筆觀察值 (佔資料的 72%)

## 技術規格

### FinBERT

FinBERT 是在金融文本上預訓練的 BERT 版本。

| 特性 | 數值 |
|------|------|
| 基礎模型 | BERT-base |
| 詞彙量 | 30,522 個詞彙 |
| 維度 | 768 |
| 層數 | 12 層 Transformer |
| 注意力頭數 | 12 |
| 總參數量 | 約 1.1 億 |
| 預訓練資料 | 金融文本 (路透社、SEC) |

**為何選擇 FinBERT 而非原始 BERT？**
- 詞彙適應金融領域
- 理解專業術語："流動性風險"、"違約條款"、"EBITDA"
- 更佳的金融情緒表達

### 注意力池化

不同於單純使用 `[CLS]` 標記，我們為每個標記學習**注意力權重**：

```python
# 公式
attention_weights = Softmax(Linear(Tanh(Linear(hidden_states))))
pooled = Σ(hidden_states × attention_weights)
```

**優點:**
1. 自動識別重要詞彙
2. 提供可解釋性（哪些詞彙影響預測）
3. 比單純 [CLS] 更好的聚合效果

### 多任務學習

模型**同時預測 5 個時間區間**：

| 目標變數 | 說明 | 意義 |
|----------|------|------|
| `bond_return` | T+0 報酬 | 即時反應 |
| `bond_return_plus_day_1` | T+1 報酬 | 次日反應 |
| `bond_return_plus_day_2` | T+2 報酬 | 短期 |
| `bond_return_plus_day_5` | T+5 報酬 | 中期 |
| `bond_return_plus_day_10` | T+10 報酬 | 長期 |

**多任務學習優點:**
- 隱式正規化（共享表徵）
- 捕捉不同時間動態
- 提升泛化能力

### 梯度檢查點

為節省 GPU 記憶體，我們使用**梯度檢查點**：

```python
self.encoder.gradient_checkpointing_enable()
```

**原理:** 不儲存所有中間激活值，而是在反向傳播時重新計算。

| 無檢查點 | 有檢查點 |
|----------|----------|
| 顯存: ~8GB | 顯存: ~4GB |
| 速度: 100% | 速度: ~80% |

## 訓練過程

### 超參數

| 參數 | 數值 | 說明 |
|------|------|------|
| 批次大小 | 4 | GPU 記憶體限制 |
| 梯度累積 | 4 | 有效批次 = 16 |
| 學習率 | 2e-5 | 微調標準值 |
| 最大序列長度 | 384 | 記憶體/上下文平衡 |
| 訓練輪數 | 20 | 含早停機制 |
| Dropout | 0.3 | 強正規化 |
| 早停耐心值 | 5 | 防止過擬合 |

### 損失函數

**遮罩 MSE 損失** - 僅對有效目標計算 MSE：

```python
def masked_mse_loss(predictions, targets, mask):
    diff = (predictions - targets) ** 2
    masked_diff = diff * mask
    return masked_diff.sum() / mask.sum()
```

為何遮罩？部分觀察值並非所有報酬都有資料（缺失值）。

### 最佳化

```python
# 帶權重衰減的 AdamW
optimizer = AdamW(params, lr=2e-5, weight_decay=0.01)

# 餘弦退火排程器
scheduler = CosineAnnealingLR(optimizer, T_max=20, eta_min=1e-7)

# 混合精度 (FP16)
scaler = GradScaler('cuda')
with autocast('cuda'):
    predictions, _ = model(input_ids, attention_mask)
```

**混合精度 (FP16):**
- 減少約 50% 記憶體使用
- 加速 GPU Tensor Core 運算
- 透過 GradScaler 維持精度

## 限制與未來改進

### 限制
1. **文字長度**: 截斷至 384 個標記（損失約 60% 文字）
2. **時間配對**: 每筆觀察值僅對應一份文件
3. **控制變數**: 無市場特徵

### 可能改進
1. **Longformer**: 處理 4096 個標記
2. **市場調整報酬**: 扣除市場報酬
3. **整合模型**: 結合數值特徵
4. **情緒分數**: 加入 FinBERT 情緒作為特徵
